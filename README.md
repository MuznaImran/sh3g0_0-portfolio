## 🎮 Portfolio concept

The experience is structured like an old-school game:

- **Character Select** — introduces SH3G0_0 / Muzna Imran
- **Player Card** — background, degree and current focus
- **Mission Select** — cybersecurity projects
- **Campaign Mode** — internship experience
- **Unlocked** — CTF achievements and evidence
- **Inventory** — technical skills, tools and frameworks
- **Secret Console** — hidden commands and easter eggs
- **Packet Trace** — animated network-style background effects
